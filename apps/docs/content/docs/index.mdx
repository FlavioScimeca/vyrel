Vyrel combines a Next.js application, an Elysia server, a GraphQL API, and a set
of focused TypeScript packages in one Bun and Turborepo workspace. This site is
the canonical guide to the repository and its two public libraries.

## What is in the repository?

Vyrel is an application monorepo and a home for reusable libraries:

- **Applications** are private deployable workspaces under `apps/`.
- **Internal packages** under `packages/` own shared database, GraphQL,
  authentication, storage, logging, and configuration concerns.
- **Public packages** under `packages/public/` are independently built, tested,
  versioned, and published to npm.

The primary runtime path is:

```text
Next.js or extension
  -> Apollo GraphQL or typed REST
  -> Elysia
  -> GraphQL Yoga and Pothos, or an Elysia REST route
  -> Effect domain services
  -> Drizzle / Better Auth / object storage
```
